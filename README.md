# Sorry, my love — static website

This site is a static bundle. It has no build step, server code, external fonts, or third-party assets.

## Preview locally

Open `index.html` in a browser. For best results, serve the folder with any static file server so all page-to-page links behave like a hosted site.

## Deploy

Upload the contents of this folder to a static hosting provider. Keep `index.html`, the other HTML pages, `love-pages.css`, and all four PNG images together in the same directory. The host should publish `index.html` as the root page.

## Page flow

`index.html` → `apology.html` → `question.html`

- **Yes, no punishment** → `no-punishment.html` → `love-letter.html`
- **No** → `pleading.html` → `no-punishment.html` → `love-letter.html`

All images are local PNG files. The displayed cat images are still illustrations, not animated GIFs.
